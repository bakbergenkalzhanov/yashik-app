# Yashik

Yashik — личный помощник. Им пользуется только владелец этого аккаунта.
Программа записывает его встречи в его Google Календарь и задачи в его Google Задачи.

## Privacy policy

Приложение получает доступ только к Google Календарю и Google Задачам владельца.
Данные хранятся на компьютере владельца и никому не передаются.
Другие пользователи приложение не используют.
